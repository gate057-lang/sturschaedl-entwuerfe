00Überblick

Wix ist ein geschlossenes System: Fertige Layouts oder Themes lassen sich nicht als Datei hochladen. Die Seiten werden deshalb im Wix-Editor gebaut, und dieses Paket liefert alles, was dafür gebraucht wird:

  • cms/ – Termine, Laufband und Mitglieder als CSV zum Importieren ins Wix-CMS
  • velo/ – fertiger Code: Termine sortieren sich selbst (kommend / Rückblick), „Nächster Auftritt“ füllt sich automatisch, Laufband liest seine Begriffe aus dem CMS
  • schriften/ – die Schriften aller fünf Designs (WOFF2, zum Hochladen in Wix)
  • bilder/ – Stierschädel-Logos, Bandfotos, Instagram-Fotos
  • vorschau/ – die fünf Entwürfe als Bild, zum Nebeneinanderlegen beim Bauen
Voraussetzungen
• Wix Premium mit verbundener Domain (für das Laufband als „Custom Element“ nötig) – ist bei sturschaedlband.de vorhanden.
• Funktioniert im normalen Wix Editor und in Wix Studio. Für den Code wird der „Dev Mode“ (Velo) eingeschaltet, das ist kostenlos.
• Die klickbaren Entwürfe zum Vergleichen: Entwürfe ansehen
Was Wix anders macht als WordPress
• Ein Design-Umschalter wie im WordPress-Theme ist in Wix nicht vorgesehen. Man legt sich auf ein Design fest; ein späterer Wechsel geht über Farben, Schriften und Startbereich (siehe Design wechseln).
• Die Handy-Ansicht passt man in Wix gesondert an (Handy-Symbol oben im Editor).

02Vorbereitung

  1. Sichern. Im Wix-Dashboard Website-Aktionen (…) → Website duplizieren. Im Duplikat bauen und erst am Ende Premium und Domain umziehen – oder direkt in der echten Seite arbeiten; Wix hebt über Website-Verlauf alte Stände auf.
  2. Schriften hochladen. Text anklicken → Text bearbeiten → Schrift-Auswahl → Schriftarten hochladen (Studio: Inspektor → Schrift → Schriften hochladen). Alle Dateien aus schriften/<Design>/ auswählen. Danach stehen sie unter „Meine Schriften“.
  3. Bilder hochladen. Medien → Hochladen → Ordner bilder/. Tipp: Die Instagram-Bilder sind kleine Vorschauen – für die echte Seite besser die Originalfotos der Band nehmen.
  4. Dev Mode einschalten. Oben im Editor Dev Mode → Dev Mode aktivieren (Studio: Code-Symbol links → Code starten). Links erscheinen nun „Seiten“, „Öffentlich & Backend“ und „Datenbanken/CMS“.

  1. Sammlung öffnen → Weitere Aktionen → Elemente in Sammlung importieren → CSV-Datei wählen.
  2. Spalten zuordnen: „Titel“ auf das vorhandene Feld „Title/Titel“, die anderen als neue Felder mit dem Typ aus der Tabelle. Bei „Datum“ das Format JJJJ-MM-TT angeben.
  3. Feld-IDs prüfen: Felder verwalten → Feld anklicken → „Feld-ID“ muss wie in der Tabelle heißen (klein geschrieben).
  4. Berechtigungen: Sammlung → Berechtigungen → „Wer darf Inhalte ansehen?“ = Jeder. Hinzufügen/Ändern nur für Admins.
  5. Ist „Sandbox“ eingeschaltet: nach dem Import Mit Live synchronisieren.
Ab jetzt pflegt die Band Termine und Laufband-Begriffe nur noch hier: CMS → Termine → + Element hinzufügen. Vergangene Termine wandern von selbst in den Rückblick.

04Code einfügen (Velo)

Alle Dateien liegen im Ordner velo/. Im Editor links im Code-Bereich anlegen und den Inhalt 1:1 hineinkopieren:

Datei im PaketWohin in Wix

velo/public/laufband.js„Öffentlich“ → + Datei laufband.js
velo/public/custom-elements/sturschaedl-laufband.js„Öffentlich“ → Ordner custom-elements anlegen → Datei sturschaedl-laufband.js
velo/seiten/Startseite.jsStartseite öffnen → Code-Leiste unten → vorhandenen Code ersetzen
velo/seiten/Termine.jsSeite „Termine“ öffnen → Code-Leiste → ersetzen

Ganz oben in Startseite.js steht const DESIGN = '1'; – hier die Nummer des gewählten Designs eintragen. Das steuert Farbe und Schrift des Laufbands.

Laufband einsetzen

  1. Hinzufügen → Einbetten & Social → Custom Element (Studio: Einbetten → Custom Element).
  2. Element anklicken → Quelle wählen → Velo-Datei → sturschaedl-laufband.js. Tag-Name: sturschaedl-laufband.
  3. Volle Breite, Höhe 58 px. Im Eigenschaften-Feld die ID laufband vergeben.
  4. Hinweis: Im Editor wird das Element in einem Rahmen angezeigt und kann dort abweichen – maßgeblich ist die Vorschau bzw. die veröffentlichte Seite.

07Handy-Ansicht

Wix erzeugt die Handy-Ansicht automatisch, sie muss aber nachgearbeitet werden (Editor oben: Handy-Symbol; Studio: Haltepunkte). Vorgaben aus den Entwürfen:

  • Seitenrand 18 px, Abschnitte 64 px Abstand oben/unten.
  • Menü als „Hamburger“, Knopf „Jetzt anfragen“ ins Menü.
  • Titelbereich: Foto als eigener Block oben (Gesichter vollständig), Schriftzug darunter, Stierschädel 78 px.
  • Fakten 2 × 2, Angebote untereinander (320 px hoch), Text-/Foto-Blöcke untereinander.
  • Termine: Datumsbox 76 px, Status unter den Titel.
  • Instagram 3 Spalten, Galerie 2 Spalten, Besetzung 2 Spalten, Fußzeile 2 Spalten.

09Design später wechseln

  1. Farben und Schriften laut Design-Karte in den Website-Design-Einstellungen austauschen – fast alle Elemente ziehen automatisch nach, wenn sie die Theme-Farben/-Schriften nutzen (beim Bauen darauf achten!).
  2. Titelbereich der Startseite nach der Tabelle „Titelbereich je Design“ umbauen.
  3. In Startseite.js die Zeile const DESIGN = '…'; auf die neue Nummer setzen (Laufband).
  4. Veröffentlichen.
Tipp: Wix-Seiten lassen sich zwischen Konten übertragen. Man kann die Seite also in einem eigenen Wix-Konto fertig bauen und danach an das Konto der Band übergeben (Dashboard → Website-Aktionen → Website übertragen).
