Bevor es losgeht

So ist diese Anleitung aufgebaut

Die Anleitung ist in nummerierte Teile gegliedert. Innerhalb eines Teils sind die Schritte nummeriert und werden der Reihe nach erledigt. Unter vielen Schritten steht in einem grünen Kasten, was Sie danach auf dem Bildschirm sehen.

Wörter in einem Rahmen wie Speichern sind Knöpfe oder Menüpunkte, die Sie anklicken. Text in grauer Schrift wie Termine tippen Sie genau so ab – auf Groß- und Kleinschreibung achten.

Wichtig zu wissenWix nimmt keine fertigen Website-Dateien an. Die Seiten werden deshalb im Wix-Editor aufgebaut – das ist Handarbeit und dauert beim ersten Mal einige Stunden. Dafür kann die Band danach Termine, Laufband und Fotos selbst pflegen. Die Bezeichnungen der Wix-Menüs können je nach Wix-Version leicht abweichen; die Wege bleiben gleich.

Was Sie brauchen

  • Einen Computer oder Laptop mit Maus (der Wix-Editor funktioniert nicht auf Handy oder Tablet).
  • Die Anmeldedaten des Wix-Kontos der Band (E-Mail und Passwort). Melden Sie sich selbst an.
  • Die Datei sturschaedl-wix-paket.zip.
  • Wix Premium mit der eigenen Domain – ist bei sturschaedlband.de vorhanden.
  • Zeit: etwa 4–6 Stunden für den Aufbau, gern auf mehrere Tage verteilt. Wix speichert zwischendurch.

Begriffe kurz erklärt

BegriffBedeutung
DashboardDie Verwaltung des Wix-Kontos. Hier liegen u. a. die Datensammlungen (CMS), Formular-Einsendungen und Einstellungen.
EditorDie Bearbeitungsansicht der Website. Man klickt Elemente direkt an und verschiebt sie mit der Maus. Geöffnet wird er im Dashboard mit Website bearbeiten.
AbschnittEin waagerechter Streifen der Seite über die volle Breite, z. B. der Titelbereich oder die Fußzeile.
ElementAlles, was auf der Seite steht: Text, Bild, Knopf, Kasten, Linie.
CMS / DatensammlungEine Tabelle im Dashboard, z. B. „Termine“. Jede Zeile ist ein Eintrag. Die Website liest diese Tabelle aus.
CSV-DateiEine einfache Tabellendatei. Im Paket liegen die Termine, Laufband-Begriffe und Mitglieder als CSV zum Einlesen.
Dev Mode / EntwicklermodusEin Schalter im Editor, mit dem man fertigen Programmcode einfügen kann. Kostenlos. Sie müssen nichts programmieren, nur kopieren und einfügen.
IDEin Name, den man einem Element gibt, damit der Code es findet, z. B. laufband. Muss genau so geschrieben werden.
Wiederholungsfeld (Repeater)Eine Liste, in der sich ein Muster für jeden Eintrag wiederholt – hier für jeden Termin eine Zeile.
Custom ElementEin selbstgebauter Baustein. Hier: das laufende Band mit den Begriffen.
VeröffentlichenErst nach Veröffentlichen (oben rechts im Editor) sehen Besucher die Änderungen.

Entwicklermodus und Code

Nur kopieren und einfügen – nichts programmieren.
1
Dev Mode einschaltenIm Editor oben in der Leiste auf Dev Mode → Dev Mode aktivieren klicken.
Links erscheint ein neuer Bereich mit geschweiften Klammern { } und unten am Bildschirm ein Code-Feld.
2
Bereich „Öffentlich“ findenLinks auf das Symbol { } klicken. Es gibt Abschnitte wie „Seiten“, „Öffentlich & Backend“. Mit der Maus auf Öffentlich zeigen → + → Neue .js-Datei.
3
Datei benennenAls Namen termine.js eintippen und Enter drücken.
Rechts öffnet sich eine leere bzw. fast leere Datei.
4
Code aus dem Paket öffnenIm Paket die Datei velo/public/termine.js öffnen:
Windows: rechte Maustaste → Öffnen mit → Editor.
Mac: rechte Maustaste → Öffnen mit → TextEdit.
5
Alles kopierenIn der geöffneten Datei alles markieren (Strg + A, Mac: ⌘ + A) und kopieren (Strg + C, Mac: ⌘ + C).
6
In Wix einfügenIn Wix in die neue Datei klicken, eventuell vorhandenen Text markieren und löschen, dann einfügen (Strg + V, Mac: ⌘ + V). Wix speichert automatisch.

Wenn etwas nicht klappt

ProblemLösung
Das Laufband ist leer oder fehlt.ID des Elements genau laufband? Tag-Name sturschaedl-laufband? Datei vollständig kopiert? Custom Elements funktionieren nur mit Premium und verbundener Domain. In der Vorschau prüfen, nicht im Editor.
Die Terminliste ist leer.Sammlung heißt genau Termine? Feld-IDs klein (datum, ort …)? Datum-Feld vom Typ „Datum“? Berechtigung „Ansehen: Jeder“? Sandbox synchronisiert?
In der Liste stehen Beispieltexte.Die IDs der Elemente in der Zeile prüfen (tTitel, tInfo … – Groß-/Kleinschreibung beachten!). Das Wiederholungsfeld darf nicht mit einem Datensatz verbunden sein.
Im Code-Feld sind rote Markierungen.Beim Kopieren fehlt etwas. Inhalt in Wix komplett löschen und die Datei noch einmal mit Strg + A kopieren und einfügen.
Falsche Farbe oder Schrift im Laufband.Im Seitencode der Startseite die Zeile const DESIGN = '…'; prüfen.
Der Kasten „Nächster Auftritt“ zeigt nichts.IDs naechsterTitel und naechsterDatum prüfen.
Etwas ist kaputt gegangen.Editor → Website → Website-Verlauf → einen früheren Stand wiederherstellen. Die Kopie „Sturschädl alt“ (Teil 4) bleibt ebenfalls erhalten.
